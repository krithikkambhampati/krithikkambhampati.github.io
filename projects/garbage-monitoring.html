Garbage Monitoring System

An on-device computer vision system for detecting garbage in real time, built as an industry-aligned project with Qualcomm.

Model
YOLOv11 (fine-tuned)
Deployment
Android, on-device
Dataset
1,500 labeled images

Overview

YOLOv11 was fine-tuned on a custom-labeled dataset of 1,500 images to recognize garbage and litter in varied real-world scenes, then packaged for on-device inference rather than a cloud round-trip — important for a detection system meant to run continuously in the field.

On-device deployment

The trained model was deployed directly into an Android app, running detection locally on the device with a real-time visualization overlay drawn over the camera feed — so a user sees bounding boxes update live as the camera moves, with no server dependency for inference.
