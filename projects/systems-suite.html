C-Shell

A Unix-like shell written in C, supporting Linux shell scripting and the full set of standard Unix commands, plus two custom built-ins.

  • Piping between commands, implemented directly over POSIX file descriptors.
  • Signal handling, so the shell behaves correctly under Ctrl-C, Ctrl-Z, and job termination.
  • Background process management — jobs can be launched, suspended, and resumed like a real shell.

C-Shark

A raw-socket packet analyzer that captures live traffic and parses TCP/IP packets layer by layer, inspecting both headers and payload rather than relying on an existing library like libpcap for the parsing logic itself.
